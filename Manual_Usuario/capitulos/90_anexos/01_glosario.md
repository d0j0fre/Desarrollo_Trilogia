# Glosario {#anx-glosario}

| Término | Significado |
|---|---|
| Activo | Equipo de la empresa que se controla por separado del inventario, como una hielera o un refrigerador. |
| Anulación de liquidación | Dejar sin efecto una liquidación de cobros hecha por error. Exige un motivo, queda en la auditoría y la ruta vuelve a quedar pendiente de liquidar. |
| Aplicación móvil | La aplicación para teléfonos Android que usa el personal en campo y en bodega. |
| Asistente | Ayudante del sistema que responde preguntas sobre su trabajo y le sugiere acciones. |
| Auditoría (bitácora) | Registro de las acciones hechas en el sistema: quién, qué y cuándo. Tiene pestañas por origen: el registro general, el de RR. HH. y el de planilla. |
| Boleta de pago | Comprobante del pago de salario de un período. |
| Campana | Ícono de notificaciones; el número indica los avisos sin leer. |
| Carrito | Lista de productos que un cliente va a comprar en la tienda en línea. |
| Combo | Producto que agrupa varios productos y se vende como uno solo. |
| Comodato | Préstamo de un equipo de la empresa a un cliente, por ejemplo un refrigerador, con un contrato. |
| Crédito | Monto que un cliente puede comprar y pagar después, hasta su límite. |
| Cuarentena | Productos devueltos o dañados que se apartan hasta decidir qué hacer con ellos. |
| Cuenta por cobrar | Dinero que un cliente le debe a la empresa. |
| Devolución | Producto que un cliente regresa. |
| Doble check (✓✓) | Marca del chat: ✓ significa que el mensaje se envió y ✓✓ que el destinatario lo recibió. |
| Estado de cuenta | Resumen de compras, pagos y saldo de un cliente. |
| Estancado (producto) | Producto con existencias que no se ha vendido durante los días de la ventana sin rotación (60 por defecto). Inteligencia de inventario lo avisa y sugiere incluirlo en una promoción. |
| Evidencia de entrega | Foto o registro que el chofer guarda al entregar un pedido. |
| Exportar Excel | Botón que descarga lo que ve en la pantalla en un archivo de Excel (.xlsx). Está en varios reportes. |
| Factura | Documento de la venta de un pedido. |
| Finalizar ruta | Marcar una ruta despachada como completada cuando ya se terminó de entregar. Es el paso previo a liquidar sus cobros. |
| Jornada | Horas de trabajo que una persona registra en un día, para que su jefatura las apruebe. |
| KPI | Indicador clave de desempeño: un número que muestra si se cumplen las metas (por ejemplo, ventas del mes). |
| Licencia | Permiso para ausentarse del trabajo (vacaciones, incapacidad u otro). |
| Liquidación de cobros | Revisión del dinero que trae un chofer al terminar su ruta frente a lo que debía cobrar. Solo se liquidan rutas finalizadas, y cada liquidación tiene su recibo en PDF. |
| Liquidación de mercadería | Revisión de la mercadería que volvió sin entregar de una ruta finalizada: la que regresa a bodega se devuelve al inventario. |
| Menú | Barra superior del sitio con los botones de cada módulo. |
| Meta de ventas | Monto de ventas que se espera que logre un vendedor en un mes. El vendedor ve su avance en **Mi meta**. |
| Módulo | Cada sección del sistema dedicada a un tema, como Inventario o Facturación. |
| Movimiento de inventario | Entrada, salida o ajuste de existencias de un producto. |
| Notificación | Aviso del sistema para usted, como una ruta asignada o un mensaje. Aparece en la campana del sitio y en la aplicación móvil. Con la aplicación cerrada no llega al teléfono (vea [Limitaciones conocidas](#anx-limitaciones)). |
| Orden de compra | Pedido de mercadería que la empresa le hace a un proveedor. |
| Pago contra entrega | Forma de pago en que el cliente paga el pedido cuando lo recibe, en lugar de usar su crédito. |
| Panel Administración | Botón del menú que reúne, por áreas, los módulos de oficina que su puesto puede abrir. |
| Pedido | Solicitud de productos de un cliente, hecha en la tienda o por un vendedor. |
| Pedido retenido | Pedido que supera un monto o una regla y espera la aprobación del Gerente. |
| Perfil (puesto) | El tipo de usuario: Administrador, Gerente, Chofer, etc. Define qué módulos ve cada persona. |
| Período de planilla | Rango de fechas que cubre un pago de planilla (quincenal o mensual), con el factor del salario mensual que se paga. |
| Permiso | Autorización para usar un módulo o una acción (por ejemplo, ver clientes o editar clientes). Los asigna el Administrador a cada perfil. Los botones de cada pantalla aparecen solo si el perfil tiene el permiso. |
| Planilla | Cálculo de los salarios del personal en un período. Un Administrador la calcula, el Gerente la aprueba y otro Administrador registra el pago. |
| Por enviar | Acciones hechas en la aplicación móvil sin señal, que esperan conexión para enviarse. |
| Presupuesto | Monto planificado de gasto o ingreso por departamento para un año. |
| Prioridad de una parada | Urgente, Alta o Normal. Al ordenar una ruta, el sistema visita primero las paradas más prioritarias y, dentro de cada nivel, la más cercana. |
| Promoción | Descuento o condición especial de venta por un tiempo. |
| Proveedor | Empresa a la que se le compra mercadería. |
| Recibo de liquidación | Comprobante en PDF que se genera al liquidar los cobros de una ruta. |
| Reclamo | Queja formal de un cliente que debe atenderse. |
| Regla de planilla | Concepto que suma o resta del salario (un bono, una cuota o una comisión), con su vigencia y la fuente que lo respalda. |
| Reporte de inventario | Lista de existencias y valor del inventario, con filtros y exportación a Excel. La ven el Administrador y el Gerente. |
| Ruta | Grupo de pedidos que un chofer entrega en un recorrido, con un vehículo asignado. Pasa por los estados Planificada, Despachada y Completada (cuando se finaliza). |
| Sesión | El tiempo entre que usted inicia sesión y la cierra. También termina sola por inactividad (45 minutos) o si el Administrador inactiva su cuenta o le cambia el puesto o la contraseña. |
| Stock (existencias) | Cantidad disponible de un producto. |
| Venta móvil | Pedido que toma un vendedor en campo, incluso sin señal. |
